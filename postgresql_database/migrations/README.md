# Database Migrations

This folder contains SQL migration scripts for the PostgreSQL database used by the Contract Insight Platform.

Contents:
- 0001_initial_schema.sql — Creates normalized tables: users, contracts, insights, deadlines, audit_logs, with indexes and triggers.

How to apply migrations:
1) Ensure PostgreSQL is running and startup.sh has been executed to create the connection file.
2) From the `postgresql_database/migrations` directory, run:
   ./apply_migrations.sh
   This script reads the psql URL from ../db_connection.txt and applies each migration in lexicographic order.

Notes:
- Migrations are written to be idempotent where feasible (using IF NOT EXISTS).
- Avoid manual edits to production databases; always add a new migration file for schema changes.
- Environment variables and connection info are generated by startup.sh and stored in:
  - postgresql_database/db_connection.txt
  - postgresql_database/db_visualizer/postgres.env

Troubleshooting:
- If you see "db_connection.txt not found", run the top-level startup script:
  cd .. && ./startup.sh
- To inspect the database quickly, you can use the db_visualizer:
  cd db_visualizer && source postgres.env && node server.js
